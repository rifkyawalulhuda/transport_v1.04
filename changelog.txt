1. fungsi input data di halaman ..\transport\admin\transaksi\input_sales_cost.php 
    	<> $nik_admin = $_POST['nik_admin']; tapi nama kolom di DB Mysql adalah nik_admin, karena scriptnya sudah berubah seharusnya diganti ke 'id_admin'
	<> tolong ubah nama kolom di Mysql menjadi 'id_admin' di aplikasi versi 0.02

2. mengubah semua pengaturan login ke halaman Admin di ..\cek_login.php = header("location:admin/index.php");

3. Menambahkan satu kolom baru di Halaman Sales Cost, yaitu Ketika Jenis Kendaraan = HB then muncul kolom baru Container Size
	<> Menambahkan satu kolom baru di Database 'trucking/sales_cost'
	<> Masuk ke 'Structure' > Add '1' column(s) 'after jenis_trip' / GO
	<> Name = 'container_size' > Type = 'VARCHAR' > Length/Values = '20' > Default = 'None' > Null = 'Checked' > Save

4. Migrasi ke Node.JS dan Vue.JS, DB (phpMyAdmin) jadi masih dibutuhkan running fitur MySQL di XAMPP

5. Running Node. JS dan Vue
	<> cd c:\xampp\htdocs\transport_v1.03\tailadmin-vuejs-1.0.0 > npm run dev
	<> cd C:\xampp\htdocs\transport_v1.03\node_backend > npm start

6. Install Mongodb Windows 11
	<> https://www.youtube.com/watch?v=rCGpx_qb1y0

7. Install Mongodb at Node Backend
	<> C:\xampp\htdocs\transport_v1.03\node_backend > npm list mongoose
							> npm install mongoose

8. Pastikan ubah alamat IP Host di Front End folder : C:\xampp\htdocs\transport_v1.03\tailadmin-vuejs-1.0.0
	<> .env.local (*pastikan type 'LOCAL File')
	<> VITE_API_URL=http://192.168.60.29:3000 (ganti host 192.168... dengan IP Host Server)

9. untuk running baru di Production (Host Server) 
	<> cd c:\xampp\htdocs\transport_v1.03\tailadmin-vuejs-1.0.0 > npm run dev -- --host 0.0.0.0


10. Halaman Repair, ubah ke DB trucking.repair kolom pada table :
	<> MODIFY tgl_kerusakan DATE NULL;
	<> MODIFY jadwal_berkala DATE NULL;

11. Jalankan Vitepress di
	<> cd C:\xampp\htdocs\transport_v1.03\docs 	> npm run dev (Local)
							> npm run dev -- --host 0.0.0.0 (Network)


12. ganti script 'lastUpdated:' di C:\xampp\htdocs\transport_v1.03\docs\.vitepress
	<> ubah dari 'true' menjadi 'false'


13. Ubah policy powershell ke Administrator
	<> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
