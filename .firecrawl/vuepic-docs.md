# Vue datepickerThe most complete datepicker solution for Vue 3

Powerful, lightweight, and reusable datepicker component to fit within any project

[Get Started](https://vue3datepicker.com/installation/)

[View on GitHub](https://github.com/Vuepic/vue-datepicker)

[Playground](https://stackblitz.com/edit/vuepic-vue-datepicker?file=src%2Fcomponents%2FPlayground.vue)

## Powerful

Supports multiple modes such as range, various pickers, multiple calendars, custom components, and many more.

## Modular

Offers a great range of features, slots and props, while providing a way to customize for specific needs.

## Customizable

Fully accessible, mobile-friendly, with built-in dark and light mode, and customizable css variables.
