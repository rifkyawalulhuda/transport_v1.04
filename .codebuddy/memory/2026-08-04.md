## Bug Fix：Detail Subcontractor 页面 DN 显示"Tidak ada data DN"

**问题**：`loadDN()` 中 `Array.isArray(data)` 永远为 false，因为 backend 返回 `{ items: [] }` 而非数组。
**修复**：`DetailSubcontractor.vue` — 将 `dnItems.value = Array.isArray(data) ? data : []` 改为 `dnItems.value = Array.isArray(data?.items) ? data.items : []`
