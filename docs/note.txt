cd backend

npm start

untuk development :
cd frontend

npm run dev

untuk production :
cd frontend

npm run build-only

lalu restart backend

restart tunnel :
cd root project

cloudflared tunnel --config <.cloudflared> ubah dengan source config disimpan\config.yml run

Migrasi Database :

cd node_backend
npm run migrate

Itu akan menjalankan semua pending migrations via dbmate. Kalau mau cek status dulu sebelum migrate:

cd node_backend
npm run migrate:status


# Di server produksi, setelah copy folder
cd node_backend

# Cek dulu tanpa apply (aman, tidak ubah apapun)
node migrate-production.js --dry-run

# Jalankan migration sesungguhnya
node migrate-production.js


Stop semua proses:
pm2 stop all

Stop proses spesifik:
pm2 stop transport-backend
pm2 stop transport-frontend

Delete (stop + hapus dari list):
pm2 delete all

Restart semua:
pm2 restart all

Lihat status:
pm2 status
