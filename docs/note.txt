Migrasi Database :

cd node_backend
npm run migrate

Itu akan menjalankan semua pending migrations via dbmate. Kalau mau cek status dulu sebelum migrate:

cd node_backend
npm run migrate:status


# Di server produksi, setelah copy folder
cd node_backend

# Cek dulu tanpa apply (aman, tidak ubah apapun)
node migrate-production.js --dry-run

# Jalankan migration sesungguhnya
node migrate-production.js

# 1. Import dump dari production ke MySQL lokal
# (dilakukan manual via MySQL client)

# 2. Adopt existing — tandai migration lama sebagai done tanpa re-run SQL
npm run migrate:adopt-existing

# 3. Apply migration baru yang belum ada di production
npm run migrate

# 4. Verifikasi semua applied
npm run migrate:status

cd node_backend

# Step 1: Jalankan fix-missing-tables (idempotent, aman dijalankan berkali-kali)
npm run migrate:fix-missing

# Step 2: Verifikasi
npm run migrate:status


Stop semua proses:
pm2 stop all

Stop proses spesifik:
pm2 stop transport-backend
pm2 stop transport-frontend

Delete (stop + hapus dari list):
pm2 delete all

Restart semua:
pm2 restart all

Lihat status:
pm2 status
