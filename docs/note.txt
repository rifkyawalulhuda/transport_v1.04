cd backend

npm start

untuk development :
cd frontend

npm run dev

untuk production :
cd frontend

npm run build-only

lalu restart backend

restart tunnel :
cd root project

cloudflared tunnel --config <.cloudflared> ubah dengan source config disimpan\config.yml run

Migrasi Database :

cd node_backend
npm run migrate

Itu akan menjalankan semua pending migrations via dbmate. Kalau mau cek status dulu sebelum migrate:

cd node_backend
npm run migrate:status
