# User Guide <Badge type="tip" text="^0.3" />

## Pendahuluan
Panduan ini membantu pengguna memahami cara menggunakan dashboard TMS untuk memantau transaksi dan performa operasional.

## Akses Dashboard
- Login ke aplikasi TMS menggunakan akun yang terdaftar.
- Setelah login, buka halaman Dashboard melalui menu utama.

## Menggunakan Filter Periode (bulan/tahun)
- Gunakan dropdown bulan dan tahun pada ringkasan Sales Cost.
- Perubahan filter akan memperbarui nilai Sales, Total Cost, dan Gross Profit.

## Membaca Ringkasan Sales Cost
- Sales menunjukkan total pendapatan periode terpilih.
- Total Cost menunjukkan total biaya operasional.
- Gross Profit adalah selisih antara Sales dan Total Cost.

## Monitoring Subcontractor
- Pantau transaksi subcontractor untuk melihat kontribusi biaya eksternal.
- Bandingkan tren subcontractor dengan transaksi internal.

## Analisis Transaksi Bulanan
- Lihat grafik Monthly Sales Transaction untuk tren per bulan.
- Gunakan filter tahun untuk membandingkan data historis.

## Detail Sales Cost (Monthly)
- Perhatikan nilai Sales, Total Cost, dan Gross Profit.
- Gunakan indikator perubahan untuk membaca perbandingan dengan periode sebelumnya.

## Melihat Demografi Pelanggan
- Gunakan peta untuk memahami sebaran pelanggan.
- Amati persentase per negara sebagai acuan fokus pasar.

## Mengelola Event Kalender
- Periksa Calendar Event List untuk aktivitas terbaru.
- Gunakan filter tanggal untuk fokus pada rentang tertentu.
- Klik See All untuk melihat kalender lengkap.

## Hak Akses User
- User memiliki akses baca terhadap ringkasan dan statistik.
- Perubahan data hanya dapat dilakukan sesuai izin yang diberikan admin.

## Troubleshooting User
- Data tidak tampil: pastikan koneksi internet stabil dan refresh halaman.
- Grafik kosong: periksa filter tahun/bulan, mungkin tidak ada data.
- Event tidak muncul: pastikan filter tanggal sesuai.
- Tidak bisa akses dashboard: periksa status login dan izin akun.
- Perubahan tidak tersimpan: cek apakah akun memiliki hak akses edit.
